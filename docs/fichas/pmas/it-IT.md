## Long Description

Unisci più file PDF in un unico documento organizzato oppure dividi un PDF lungo in nuovi file con intervalli di pagine più facili da gestire.

Con Unisci e dividi PDF puoi decidere l’ordine dei documenti, i punti di divisione, gli intervalli di pagine e il modo in cui verranno creati i file finali.

Seleziona più PDF, disponili nell’ordine che preferisci e crea un nuovo documento. In alternativa, scegli un PDF e dividilo usando i segnalibri già presenti, le pagine che selezioni, un numero definito di gruppi bilanciati o un numero massimo di pagine per ogni file.

Con l’app puoi:

* Unire più file PDF in un unico documento
* Modificare l’ordine prima dell’unione
* Usare i segnalibri già presenti nel PDF
* Scegliere le pagine da cui inizieranno i nuovi file
* Creare un numero definito di gruppi bilanciati per pagine
* Impostare un numero massimo di pagine per ogni risultato
* Controllare in anteprima gli intervalli di pagine
* Scegliere o regolare una pagina di copertina quando disponibile
* Salvare nuovi file PDF
* Aprire i risultati con applicazioni compatibili
* Condividere i PDF creati
* Ritrovare i risultati nella sezione “I miei PDF”

I file originali rimangono disponibili separatamente.

Le operazioni di unione e divisione vengono eseguite sul dispositivo. Non è necessario creare un account e il contenuto dei tuoi PDF non viene caricato online per effettuare queste operazioni.

Usa l’app per riunire un rapporto e i suoi allegati, organizzare documenti amministrativi, raccogliere ricevute correlate, separare materiale di studio o dividere un PDF lungo in file più pratici da utilizzare e condividere, senza ricorrere a programmi complessi sul computer.

## Notes / Assumptions

* Il numero massimo di pagine indica quante pagine può contenere ogni risultato, non una dimensione massima in byte o megabyte.
* “Un numero definito di gruppi bilanciati” indica una distribuzione approssimativamente uniforme delle pagine, non file identici per dimensione.
* I segnalibri devono essere presentati come elementi già presenti nel PDF selezionato.
* “Aprire” significa utilizzare un’applicazione compatibile installata sul dispositivo.
* “I miei PDF” deve corrispondere esattamente al nome utilizzato nell’interfaccia.
* La sezione “I miei PDF” deve apparire come gestione locale dei risultati, non come lettore, editor o archivio cloud.
* Gli esempi visivi devono utilizzare rapporti, allegati, ricevute, materiale di studio o documenti amministrativi fittizi.
* Non devono comparire nomi reali, indirizzi, firme, numeri di conto, identificativi, codici QR o codici a barre utilizzabili.
* Non devono essere copiati moduli ufficiali italiani, loghi istituzionali, marche da bollo o timbri reali.
* L’app non deve essere presentata come scanner, strumento OCR, compressore, riparatore, convertitore, strumento di firma o rimozione password.
* Non deve essere garantita la validità delle firme digitali dopo la riscrittura del PDF.
* Non deve essere promessa la conservazione perfetta di moduli interattivi, segnalibri complessi, etichette di pagina, collegamenti interni, annotazioni, allegati o azioni avanzate.
* La pagina di copertina deve rimanere una funzione secondaria di preparazione del risultato.
* “Sul tuo dispositivo”, “Nessun account” e “Nessun caricamento dei documenti” sono messaggi di fiducia secondari, non la proposta principale.
* Non utilizzare “100% offline” se annunci, acquisti o verifiche della licenza richiedono una connessione.
