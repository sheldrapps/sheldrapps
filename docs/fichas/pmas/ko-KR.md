# PDF 병합 및 분할 — ko-KR Play Store Listing

## Purpose

여러 PDF를 하나의 문서로 합치거나 하나의 긴 PDF를 여러 파일로 나눌 수 있는, 깔끔하고 유연한 PDF 정리 도구로 소개한다.

이름이 짧고 명확하며, 앱의 두 가지 주요 기능을 바로 전달합니다.

사용자 대상의 제목과 설명에서는 더 친숙한 “합치기”와 “나누기”를 함께 사용할 수 있습니다.

## Long Description

여러 PDF 파일을 원하는 순서대로 합쳐 하나의 새 문서를 만들거나, 긴 PDF를 명확한 페이지 범위를 가진 여러 개의 새 파일로 나눌 수 있습니다.

PDF 병합 및 분할에서는 파일 순서, 분할 위치, 페이지 범위와 생성될 결과 파일을 직접 선택할 수 있습니다.

여러 PDF를 선택하고 원하는 순서로 정렬한 뒤 하나의 새 문서로 합쳐 보세요. 하나의 PDF를 나눌 때는 문서에 이미 포함된 북마크, 직접 선택한 페이지 위치, 지정한 수의 균형 잡힌 페이지 그룹 또는 파일당 최대 페이지 수를 기준으로 사용할 수 있습니다.

주요 기능:

* 여러 PDF 파일을 하나의 문서로 병합
* 병합하기 전에 파일 순서 변경
* PDF에 이미 포함된 북마크를 기준으로 분할
* 새 PDF가 시작될 페이지 직접 선택
* 지정한 수의 균형 잡힌 페이지 그룹 생성
* 결과 파일별 최대 페이지 수 설정
* 파일을 만들기 전에 페이지 범위와 파일명 미리보기
* 지원되는 경우 결과의 표지 페이지 선택 및 조정
* 새 PDF 파일 저장
* 호환되는 앱으로 결과 열기
* 생성한 PDF 파일 공유
* 저장한 결과를 “내 PDF”에서 다시 확인

원본 파일은 변경되지 않으며 생성된 결과와 별도로 유지됩니다.

병합과 분할 처리는 기기에서 이루어집니다. 계정을 만들 필요가 없으며, 이러한 작업을 위해 PDF 콘텐츠가 온라인으로 업로드되지 않습니다.

보고서와 첨부 자료를 하나로 합치고, 제출 서류를 올바른 순서로 정리하고, 학습 자료에서 필요한 페이지를 분리하거나, 긴 PDF를 사용하고 공유하기 쉬운 파일로 나눠 보세요. 복잡한 PC 프로그램을 사용할 필요가 없습니다.

* 여러 PDF에서 하나의 새 PDF 생성
* 하나의 PDF에서 여러 새 파일 생성
* 사용자가 선택한 순서와 병합 결과

## Notes / Assumptions

* “균형 잡힌 파트”는 페이지 수를 가능한 한 고르게 배분한다는 의미이며, 결과 파일의 바이트 크기가 동일하다는 의미가 아니다.
* 최대 페이지 수는 각 결과에 포함되는 페이지 수의 상한이며, 바이트나 MB 단위의 최대 파일 크기가 아니다.
* 북마크 분할은 선택한 PDF에 이미 북마크가 있는 경우 사용할 수 있는 방식으로 설명한다.
* “열기”는 기기에 설치된 호환 앱으로 파일을 여는 것을 의미한다.
* “내 PDF”는 앱 인터페이스에 표시되는 실제 명칭과 정확히 일치해야 한다.
* “내 PDF” 화면은 PDF 리더, 편집기 또는 클라우드 저장소가 아니라 생성 결과를 관리하는 화면으로 보여야 한다.
* 예시 콘텐츠는 가상의 보고서, 첨부 자료, 학습 자료, 영수증, 설명서 또는 제출 문서를 사용한다.
* 실제 이름, 주소, 서명, 계좌 번호, 식별 번호, 사용 가능한 QR 코드나 바코드를 표시하지 않는다.
* 실제 한국 행정 서류, 주민등록증, 여권, 은행 거래 내역, 학교 서식, 기관 로고나 공식 도장을 복제하지 않는다.
* 앱이 스캔, OCR, 압축, 복구, 형식 변환, 비밀번호 제거 또는 전자 서명을 수행하는 것처럼 보이지 않도록 한다.
* PDF를 다시 작성한 뒤에도 디지털 서명이 유효하다고 보장하지 않는다.
* 대화형 양식, 복잡한 북마크, 페이지 레이블, 내부 링크, 주석, 첨부 파일 또는 고급 동작이 완전히 보존된다고 표현하지 않는다.
* 표지 페이지는 문서와 페이지 정리 이후의 보조 기능으로 유지한다.
* “기기에서 처리”, “계정 불필요”, “문서 업로드 없음”은 신뢰를 돕는 메시지이며, 주요 제품 약속이 아니다.
* 광고, 구매 또는 라이선스 확인에 인터넷 연결이 필요하다면 “100% 오프라인”이라고 표현하지 않는다.
