## Long Description

将多个 PDF 文件按所需顺序合并为一个新文档，或把较长的 PDF 拆分为多个带有清晰页面范围的新文件。

使用 PDF合并与拆分，你可以决定文件顺序、拆分位置、页面范围以及最终生成哪些文件。

选择多个 PDF，调整排列顺序，然后创建一个新的文档。你也可以选择一个 PDF，按照其中已有的书签、自行选择的页面位置、指定数量的均衡页面组，或每个结果文件的最大页数进行拆分。

你可以：

* 将多个 PDF 文件合并为一个文档
* 在合并前调整文件顺序
* 使用 PDF 中已有的书签进行拆分
* 自行选择每个新文件的起始页面
* 创建指定数量的均衡页面组
* 设置每个结果文件的最大页数
* 创建前预览页面范围和文件名
* 在支持时选择或调整结果的封面页
* 保存新生成的 PDF 文件
* 使用兼容的应用打开结果
* 分享创建的 PDF 文件
* 在“我的 PDF”中再次查看结果

原始文件不会被修改，并会与新生成的文件分开保留。

合并和拆分处理都在你的设备上完成。不需要创建账号，也不会为了执行这些操作而上传 PDF 内容。

你可以合并报告及其附件，整理申请材料，归纳相关票据，分开学习资料中的指定页面，或将较长的 PDF 拆分成更容易使用和分享的文件，无需使用电脑上的复杂软件。

## Notes / Assumptions

* 5 张截图中，书签、指定页面、文件数量、自定义拆分位置和最大页数统一在第 3 张展示。
* 第 3 张截图不得同时展开所有设置，只突出一种选中的方式。
* “均衡页面组”表示尽量均匀地分配页面，不代表生成的文件在字节大小上完全相同。
* 最大页数是每个结果可包含的页面数量上限，不是字节或 MB 单位的最大文件大小。
* 按书签拆分仅在所选 PDF 已经包含书签时可用。
* “打开”是指通过设备上安装的兼容应用打开文件。
* “我的 PDF”必须与应用界面中实际使用的名称完全一致。
* “我的 PDF”应表现为本地结果管理页面，而不是阅读器、编辑器或云端文件库。
* 示例内容应使用虚构的报告、附件、学习资料、票据、说明文档或申请材料。
* 不得显示真实姓名、地址、签名、账号、身份证明号码、可用的二维码或条形码。
* 不得复制真实的中国身份证、护照、银行卡账单、政府表格、机构标识、公章或学校正式文件。
* 视觉内容不得让用户误以为应用支持扫描、OCR、压缩、修复、格式转换、密码移除或电子签名。
* 不得保证 PDF 重新写入后数字签名仍然有效。
* 不得承诺完整保留交互式表单、复杂书签、页面标签、内部链接、批注、附件或高级操作。
* 封面页应保持为文档和页面整理之后的辅助功能。
* “在设备上处理”“无需账号”“不会上传文档”是辅助信任信息，不是主要产品承诺。
* 如果广告、购买或许可证验证需要联网，不得使用“100% 离线”。
