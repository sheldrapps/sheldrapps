# PDF Merge & Split — en-US Golden Play Store Listing

## Purpose

Create a Play Store listing that clearly positions PDF Merge & Split as a focused utility for reorganizing PDF documents and creating new PDF files.

The app has two main jobs:

**Merge multiple PDF files into one organized document.**

**Split one PDF into new files using existing bookmarks, selected page boundaries, balanced page groups, or a maximum number of pages per file.**

The listing should make the app feel flexible, controlled, private, and easy to use. It should not present PDF Merge & Split as a full PDF editor, PDF reader, scanner, OCR tool, compressor, file converter, password-removal tool, cloud service, electronic-signature tool, or AI document processor.

The core message should feel like this:

**Combine several PDFs into one document, or divide a long PDF into the page ranges you need. Control the order, review the output, and save new PDF files directly on your device.**

---

## App Name

PDF Merge & Split

## Why

“PDF Merge & Split” clearly communicates both primary functions and includes the strongest search term: **PDF**.

It is direct, understandable, and more descriptive than using the internal acronym “PMAS” as the public-facing name.

The name supports searches related to:

* merging PDF files
* combining documents
* splitting PDF files
* separating PDF pages
* extracting page ranges
* creating smaller PDF documents by page count

No alternate app name is needed for en-US.

## Short Description

Merge, organize, and split PDF files on your device

## Why

* merge PDF files

## Long Description

Merge multiple PDF files into one document or split a long PDF into smaller, clearly organized files.

PDF Merge & Split gives you flexible control over how documents are combined and how pages are divided.

Choose several PDF files from your device, place them in the order you want, review the planned result, and create one new PDF containing all of them.

You can also choose one PDF and divide it using the method that best fits your document.

With PDF Merge & Split, you can:

* Merge multiple PDF files into one document
* Change the order of PDFs before merging
* Review the planned merged result
* Split a PDF using existing bookmarks when available
* Choose custom page boundaries
* Divide a PDF into a selected number of balanced page groups
* Set a maximum number of pages for each generated file
* Review the page ranges before creating the results
* Choose or adjust a result cover page when supported
* Save newly created PDF files
* Open completed PDFs with compatible apps
* Share created PDF files
* Find saved results in My PDFs
* Change language and theme settings
* Remove ads with an upgrade option

Use bookmark-based splitting when the source PDF already contains useful bookmarks.

Use custom split points when you want to decide exactly where each new PDF begins.

Use balanced parts when you want a selected number of files with a similar number of pages.

Use maximum-pages splitting when you want each result to contain no more than a selected number of pages.

PDF Merge & Split creates new result files from the PDFs you select. Your source documents remain available separately.

Document processing happens on your device.

No accounts.  
No document uploads for merging or splitting.  
Private control over your PDF files.

The app is useful for students, teachers, office workers, researchers, freelancers, administrators, and anyone who manages reports, applications, supporting documents, study material, manuals, forms, receipts, or long PDF files.

Whether you need to combine a report with its appendices, organize several related documents into one file, separate specific page ranges, or divide a long PDF into easier-to-use parts, PDF Merge & Split provides a direct workflow without complicated desktop tools.

The app focuses on one practical goal:

**organize PDF documents and create the PDF files you need.**
