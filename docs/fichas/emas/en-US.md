# EPUB Merger & Splitter — en-US Play Store Listing

## Purpose

Create a clear, conversion-focused Play Store listing for a practical EPUB organization utility.

The listing should communicate that users can:

* Merge several EPUB files into one organized book
* Control the order before merging
* Split one EPUB using several different methods
* Choose and adjust the result cover
* Save, open, and share the EPUB files they create
* Process their book content directly on their device

The app should not be positioned as a full EPUB editor, ebook reader, format converter, repair tool, cloud service, or DRM utility.

## Long Description

Merge multiple EPUB files into one organized book or split a large EPUB into new files using the method that works best for you.

With EPUB Merger & Splitter, you control how your books are arranged and how the resulting EPUB files are created.

Select several EPUBs, place them in the order you want, choose the result cover, and create one new book containing all of them.

You can also select one EPUB and divide it in several ways:

* Split by detected chapters
* Split by available sections
* Divide the content into a selected number of parts
* Add your own split points
* Split using a maximum file-size setting

Review how the content will be distributed before creating the result.

With EPUB Merger & Splitter, you can:

* Merge multiple EPUB files into one book
* Reorder EPUBs before merging
* Choose and adjust the result cover
* Split an EPUB by chapters or sections
* Create a selected number of parts
* Set custom split points
* Use a maximum size when creating smaller EPUB files
* Save newly created EPUBs
* Open results with compatible installed apps
* Share created EPUB files
* Find saved results again in My EPUBs
* Change the app language and theme
* Remove ads with an upgrade option

Your source EPUB files remain available separately.

EPUB content is processed on your device and is not uploaded for merging or splitting. No account is required.

Combine related books into one volume, organize serialized content, divide study material, or turn a large EPUB into smaller and easier-to-manage files without relying on complicated desktop software.

EPUB Merger & Splitter focuses on one practical job: giving you clear control over how your EPUB files are combined, divided, and saved.

## Notes / Assumptions

* “Maximum size” is a splitting criterion and must not be presented as compression.
* “Selected number of parts” is safer than promising files of exactly equal size.
* Chapter and section splitting depends on structure available in the source EPUB.
* “Open” means opening the result with a compatible installed application.
* The app should not imply that it reads EPUBs internally.
* Source EPUBs and generated results must remain visually distinguishable.
* Do not claim unlimited inputs unless practical Android memory and processing behavior have been validated.
* Example titles and covers must use authorized or public-domain content in the United States.
* Public-domain source texts may still have copyrighted modern translations or cover designs.
