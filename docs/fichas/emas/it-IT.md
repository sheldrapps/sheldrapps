## Long Description

Unisci più file EPUB in un unico volume organizzato oppure dividi un EPUB di grandi dimensioni in nuovi file più facili da gestire.

Con Unisci e dividi EPUB puoi decidere l’ordine dei contenuti, il metodo di divisione, la copertina e il modo in cui verranno creati i file finali.

Seleziona più EPUB, disponili nell’ordine che preferisci e crea un nuovo libro. In alternativa, scegli un EPUB e dividilo in base ai capitoli o alle sezioni disponibili, in un numero definito di parti, utilizzando punti di divisione personalizzati o un limite massimo di dimensione.

Con l’app puoi:

* Unire più file EPUB in un unico libro
* Modificare l’ordine prima dell’unione
* Scegliere e regolare la copertina del risultato
* Dividere un EPUB in base ai capitoli o alle sezioni disponibili
* Creare un numero definito di parti
* Scegliere punti di divisione personalizzati
* Utilizzare un limite massimo di dimensione
* Controllare in anteprima come verrà distribuito il contenuto
* Salvare nuovi file EPUB
* Aprire i risultati con applicazioni compatibili
* Condividere gli EPUB creati
* Ritrovare i risultati nella sezione “I miei EPUB”

I file originali rimangono disponibili separatamente.

Le operazioni di unione e divisione vengono eseguite sul dispositivo. Non è necessario creare un account e il contenuto dei tuoi EPUB non viene caricato online per effettuare queste operazioni.

Usa l’app per organizzare raccolte, riunire volumi collegati o dividere libri di grandi dimensioni in file più pratici, senza ricorrere a programmi complessi sul computer.

## Notes / Assumptions

* Il limite massimo di dimensione è un criterio pratico di divisione, non una garanzia di dimensione esatta.
* “Un numero definito di parti” è preferibile a “parti uguali” se i file non sono realmente identici per dimensione.
* “Aprire” significa utilizzare un’applicazione compatibile installata sul dispositivo.
* “I miei EPUB” deve corrispondere esattamente al nome utilizzato nell’interfaccia.
* La sezione “I miei EPUB” deve apparire come gestione locale dei risultati, non come lettore o negozio.
* Gli esempi visivi devono utilizzare contenuti autorizzati o di pubblico dominio in Italia.
* Traduzioni moderne e copertine recenti devono essere verificate separatamente anche quando l’opera originale è di pubblico dominio.
* Le immagini non devono suggerire che l’app fornisca, venda o scarichi i libri mostrati.
