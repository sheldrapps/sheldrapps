# EPUB 병합 및 분할 — ko-KR Play Store Listing

## Purpose

여러 EPUB을 하나로 합치거나 하나의 EPUB을 여러 파일로 나눌 수 있는, 깔끔하고 유연한 EPUB 정리 도구로 소개한다.

## App Name

Current localized name from the app:

Reasoning:

“병합”과 “분할”은 파일 작업을 정확하게 설명하는 자연스러운 용어입니다.

이름이 짧고 명확하며, 앱의 두 가지 주요 기능을 바로 전달합니다.

사용자 대상의 제목과 설명에서는 더 친숙한 “합치기”와 “나누기”를 함께 사용할 수 있습니다.

## Long Description

여러 EPUB 파일을 원하는 순서대로 합쳐 하나의 새 EPUB을 만들거나, 큰 EPUB을 여러 개의 새로운 파일로 나눌 수 있습니다.

EPUB 병합 및 분할에서는 파일 순서, 분할 방식, 새 EPUB의 표지와 생성될 파일을 직접 선택할 수 있습니다.

여러 EPUB을 선택하고 원하는 순서로 정렬한 뒤 하나의 새 책으로 합쳐 보세요. 하나의 EPUB을 나눌 때는 EPUB에 포함된 챕터나 섹션, 지정한 수의 파트, 직접 선택한 분할 지점 또는 최대 파일 크기를 기준으로 사용할 수 있습니다.

주요 기능:

* 여러 EPUB 파일을 하나의 책으로 병합
* 병합하기 전에 파일 순서 변경
* 새 EPUB에 사용할 표지 선택 및 조정
* EPUB에 포함된 챕터나 섹션을 기준으로 분할
* 지정한 수의 파트 생성
* 원하는 위치에 분할 지점 설정
* 최대 파일 크기를 기준으로 분할
* 파일을 만들기 전에 콘텐츠 배치 미리보기
* 새 EPUB 파일 저장
* 호환되는 앱으로 결과 열기
* 생성한 EPUB 파일 공유
* 저장한 결과를 “내 EPUB”에서 다시 확인

원본 파일은 변경되지 않으며 생성된 결과와 별도로 유지됩니다.

병합과 분할 처리는 기기에서 이루어집니다. 계정을 만들 필요가 없으며, 이러한 작업을 위해 EPUB 콘텐츠가 온라인으로 업로드되지 않습니다.

여러 권으로 나뉜 책이나 관련 EPUB을 하나로 정리하고, 큰 책이나 학습 자료를 관리하기 쉬운 파일로 나눠 보세요. 복잡한 PC 프로그램을 사용할 필요가 없습니다.

## Market Angle Decision

깔끔한 정리와 유연한 결과 제어를 중심으로 한다.

사용자가 다음 관계를 한눈에 이해할 수 있어야 한다:

* 여러 EPUB에서 하나의 새 EPUB 생성
* 하나의 EPUB에서 여러 새 파일 생성
* 사용자가 선택한 순서와 병합 결과
* 사용자가 선택한 분할 방식과 생성 결과

추상적인 자동화나 과장된 속도보다는 실제 UI를 통해 순서, 분할 방식, 표지와 결과 파일을 명확하게 보여 준다.

## Notes / Assumptions

* “동일한 파트”는 결과 파일이 실제로 같은 크기가 아닌 경우 사용하지 않는다.
* 대신 “지정한 수의 파트” 또는 “선택한 수의 파트”를 사용한다.
* 최대 파일 크기는 분할 기준이며 정확한 출력 바이트를 보장하지 않는다.
* “열기”는 기기에 설치된 호환 앱으로 파일을 여는 것을 의미한다.
* “내 EPUB”은 앱 인터페이스에 표시되는 실제 명칭과 정확히 일치해야 한다.
* “내 EPUB” 화면은 전자책 리더나 서점이 아니라 생성 결과를 관리하는 화면으로 보여야 한다.
* 예시 콘텐츠는 한국에서 사용할 수 있는 허가된 자료 또는 퍼블릭 도메인 작품으로 제한한다.
* 원작이 퍼블릭 도메인이더라도 현대 번역과 최근 표지 디자인은 별도로 확인한다.
* 앱이 화면에 표시된 책을 제공하거나 판매하거나 다운로드하는 것처럼 보이지 않도록 한다.
