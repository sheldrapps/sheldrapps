# Editor fonts: licensing record

This folder contains the original editor fonts plus the current additions.
Each font was kept only when its local notice recorded commercial permission
or an open license that permits redistribution with software. License records
are shipped next to the font files.

This is an engineering record, not legal advice. Keep the notices with any
redistributed build and re-check upstream terms before adding new fonts.
